# Jobs to be Done — Riverside Library Lending

A fictional document. Riverside Community Library is replacing the two systems it uses to lend books and run events. This file lists what the people who do that work are trying to accomplish. It exists as a test fixture and as an example of the format; nothing in it describes a real organisation.

A job is an achievement, not a task. "Write the loan on a paper sheet" is a task and it will disappear with the old software. "Keep lending when the network is down" is a job, and it will still be true in the new system. Keeping the two apart is the point of this document.

Each job is written as a situation, a need, and an outcome, so it can be read on its own. Under each one is a note on how the work gets done today, and a line saying how well we actually know it.

**How to read the confidence line.** Every job ends with one of three:

- **Confirmed** — the person who does this job has read it and agreed. Names them and dates it.
- **Described** — someone talked about it in a session. Often a colleague rather than the person doing it.
- **Derived** — taken from documentation. Nobody has been asked.

## How this document stays current

**Jobs are stable; the notes under them are not.** A job like "keep lending when the network is down" will still be true in five years. The paragraph describing how it happens today will not.

**Update the confidence line in the same session where you learn something.** A job marked Derived and a job marked Confirmed look identical without it.

**Move jobs from Described to Confirmed by reading them back.** Show someone the few jobs that belong to them and ask what is wrong.

**What cannot be filled in from a desk:** how long each job takes and how often it happens. Without those two numbers this list says what matters but not what matters most.
